# MiniLang Starter

[简体中文](README.md) | [English](README.en.md)

This directory is the student-visible course-project starting point. It provides only the build system, public interfaces, SourceManager/Diagnostic infrastructure, CLI entry point, and smoke tests. Students implement the lexer, parser, static semantics, control-flow lowering, and JIT core. LLVM, platform, and dependency policy follows `docs/version-policy.en.md`.
