## 可以先开展的教学

现在可以试讲 LLVM IR/SSA、C++ API、局部 Pass 与三个 MLIR CPU 实验。教师可先使用公开参考代码，要求学生解释和修改不同条件，而不是以隐藏答案为前提评分。前端和完整编译器作业尚需教师参考实现，不能用学生的首次提交充当未经审查的标准答案。

## 维护与勘误

变更语言规则时，先给原行为、修订行为与最小程序，再同步契约、双语讲义、公开测试和评分。升级工具链时重跑基础和 MLIR 测试，并重新检查所有源级语义案例。每次开课保留独立课程版本，不在学期中自动追踪 main。

测试数量不是成熟度指标。不得以填入更多测试名称、标记 skip、只编译空外壳或把上游 check-mlir 结果计为课程编译器正确性。对未完成项写明范围，比发布一个没有依据的完成标签更有助于备课。
